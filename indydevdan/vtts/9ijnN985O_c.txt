ARCHITECTURE OVERVIEW:
Claude Agents → Hook Scripts → HTTP POST → Bun Server → SQLite → WebSocket → Vue Client

This creates a complete chain for:
1. Capturing hook events from Claude Code execution
2. Sending events to a backend server
3. Storing events in a structured database
4. Broadcasting events via WebSocket
5. Real-time visualization in Vue client

KEY HOOK TYPES:
- Agent lifecycle hooks (initialization, execution, completion)
- Task hooks (start, progress, completion)
- Error hooks (debugging information)
- Custom hooks (user-defined monitoring points)

## PRODUCTION NOTES

### Music:
- **0:00-0:06**: Tension build (dark, urgent)
- **0:06-0:24**: High energy (electronic, confident)
- **0:24-0:30**: Clear resolution (punchy, memorable)

### Pacing:
- **Ultra-fast cuts**: Maximum 2-3 seconds per shot
- **No wasted frames**: Every second must deliver value
- **Clear audio**: Voiceover must be crisp and fast but understandable

### Key Simplifications:
- ❌ No long setup sequences
- ❌ No elaborate team collaboration montage
- ❌ No detailed sprint explanation
- ✅ Problem → Solution → Hero Moment → CTA
- ✅ Golf course still featured (THE differentiator)
- ✅ Core value prop crystal clear

### Platform Optimization:

#### Instagram Reels / TikTok:
- Vertical format (9:16)
- Captions essential (80% watch muted)
- Hook in first 2 seconds: "You closed the deal..."
- Pattern interrupt: AI interface activation

#### YouTube Shorts:
- Can use as-is (9:16)
- Add "Watch full version" end card

#### Paid Ads (Facebook/Instagram/LinkedIn):
- Square format (1:1) for feed
- First 3 seconds = everything (auto-play scroll)
- Test versions with/without voiceover

#### Twitter/X:
- Keep at exactly 30 seconds
- Add closed captions
- Optimize for mobile viewing

## MOBILE-FIRST CONSIDERATIONS

Since most views will be mobile:

- **Text size**: Large, bold, high contrast
- **Faces**: Close-ups work better than wide shots
- **Motion**: Constant movement keeps attention
- **Sound**: Assume 50% will watch muted
- **Load time**: Optimize file size for quick loading

This 30-second version is built for scroll-stopping, thumb-stopping power.

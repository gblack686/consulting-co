## Answers

### A1
**C) Building systems that build systems**
Phase Two is about becoming a "commander of compute" who builds systems that build systems.

### A2
**B) Context, Model, Prompt, Tools**
The Core Four are the fundamental leverage points of agentic coding. See [[../diagrams/core-four.excalidraw]].

### A3
**C) Stop coding (typing code manually)**
Tactic #1 is "Stop Coding" - your hands and mind are no longer the best tools for writing code.

### A4
**C) Using compute to build systems that build systems**
A Commander of Compute doesn't just prompt to generate code - they build systems of leverage.

### A5
**C) Transforming codebases into self-operating machines**
The irreplaceable engineer transforms their codebase into a self-operating machine.

### A6
**B) AI coding (code generation)**
Phase One was AI coding - using AI to generate code. Phase Two is agentic coding.

### A7
**B) The Core Four**
The Big Three (Context, Model, Prompt) became the Core Four when Tools were added.

### A8
**B) Running Claude Code from any language with terminal access**
Programmable agentic coding means Claude Code can be run from any programming language.

### A9
**C) Planning, reviewing, and creating closed loop structures**
Engineers in Phase Two focus on planning, reviewing, and creating closed loop structures.

### A10
**B) Writing code**
Engineering was never about writing code - it's about building systems of leverage.

### A11
**False** - AI coding was Phase One. Agentic coding (Phase Two) is needed to become irreplaceable.

### A12
**True** - Claude Code is programmable from any language with terminal access.

### A13
**False** - The 10X opportunity is about achieving 10X leverage, not spending 10X time.

### A14
**False** - Code understanding is still critically important, but we're not coding anymore.

### A15
**True** - This is the definition of the irreplaceable engineer in Phase Two.

### A16
**replace** - "To become an irreplaceable engineer, you will replace yourself."

### A17
**Tools** - Context, Model, Prompt, and Tools make up the Core Four.

### A18
**Tactical** - TAC stands for Tactical Agentic Coding.

### A19
An engineer builds systems of leverage that produce valuable outcomes for users and customers. A coder just writes code. The difference is massive - engineers think systemically about outcomes while coders focus on implementation.

### A20
By building systems that automate your own work (self-operating machines), you become irreplaceable because you create exponential value. Vibe coders who don't build these systems can't replicate this leverage.

## Usage

Each TAC lesson folder contains:
- `loot.md` - Key concepts and takeaways from the lesson
- `transcript.txt` - Full video transcript (symlinked or copied)
- `README.md` - Extracted commands, agents, ADWs, concepts

## Leveraging Transcripts

1. **Search for specific concepts**: Use grep to find where concepts are discussed
2. **Context for agents**: Feed transcripts as context for deeper understanding
3. **Cross-reference loot**: Validate loot.md concepts against original source
4. **Quote extraction**: Pull exact quotes for documentation

## Answers

### A1
**B) Adopt Your Agent's Perspective**

### A2
**B) In-Agent and Through-Agent leverage points**
In-Agent are internal (Core Four), Through-Agent are external things agents interact with.

### A3
**C) Tests**
Tests are a Through-Agent leverage point, not part of the Core Four.

### A4
**B) It starts each session with no context or memories**
Each new session is ephemeral - your agent has no memory of previous sessions.

### A5
**B) Getting results right the first time without iteration**
One-shot success means your agent completes the task correctly on the first attempt.

### A6
**B) Plan, Code, Test, Review, Document**
The compressed, focused SDLC built for Phase Two.

### A7
**B) To help agents understand what they need to complete tasks**
Agent documentation focuses on what the agent needs, not what humans need.

### A8
**B) They enable agents to validate and self-correct**
If your agent can run tests, it can validate its own work and fix mistakes.

### A9
**B) Agentic prompts with deterministic code**
ADWs synthesize agentic prompts with deterministic code for reusable workflows.

### A10
**B) Longer runs, Reduced iterations, Increased success rates**
These KPIs measure agentic coding improvement.

### A11
**B) They provide structured information and clear contracts**
Types communicate expectations clearly to agents.

### A12
**B) The gap between what you can do and what your agent can do**
Adopting your agent's perspective closes this capability gap.

### A13
**True** - Context is literally everything in the context window.

### A14
**False** - Agent documentation is different, focusing on agent needs.

### A15
**False** - Planning meta-work dramatically improves agent success rates.

### A16
**True** - Good architecture helps agents navigate your codebase.

### A17
**False** - The Core Four are In-Agent (internal) leverage points.

### A18
**True** - Stacking all 12 leverage points maximizes one-shot success.

### A19
**True** - To perform like you, agents need your information, tools, and resources.

### A20
**False** - Through-Agent leverage points are external (Tests, Planning, ADWs, etc.).

### A21
| Leverage Point | Category |
|----------------|----------|
| Context | **In-Agent** |
| Tests | **Through-Agent** |
| Model | **In-Agent** |
| Planning | **Through-Agent** |
| Prompt | **In-Agent** |
| ADWs | **Through-Agent** |

### A22
**blind** - "Your agent is brilliant, but blind."

### A23
**one-shot** - One-shot agentic coding success.

### A24
"Can our agent see everything it needs to complete the task successfully?" Always think from your agent's perspective about what context it needs.

### A25
The four In-Agent leverage points are:
1. **Context** - What the agent can see
2. **Model** - Which AI model is used
3. **Prompt** - The instructions given
4. **Tools** - Capabilities available to the agent

They're "In-Agent" because they're internal to and always with your agent, as opposed to Through-Agent points which are external things the agent interacts with.

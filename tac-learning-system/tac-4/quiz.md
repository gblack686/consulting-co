### A23
**classes** - ADWs solve problem classes, not individual problems.

### A24
The PITER Framework has four elements:
1. **P - Prompt Input (GitHub Issues)**: Create issues that serve as input for AFK agents. Can be created from anywhere.
2. **T - Trigger (GitHub Webhooks)**: When an issue is created, webhooks automatically kick off the workflow.
3. **E - Environment (Dedicated)**: Agents run in isolated environments without interfering with your main setup.
4. **R - Review (Pull Requests)**: After completion, agents create PRs for review, giving visibility and control.

These work together to create autonomous workflows that run without direct intervention.

### A25
AFK agents outperform cloud tools because:
- They know YOUR codebase specifically
- They understand YOUR domain-specific problems
- They contain your engineering practices
- They're built for your workflow, not generic "for everyone" solutions
- You control and can improve them over time
- They're not limited by cloud tool constraints

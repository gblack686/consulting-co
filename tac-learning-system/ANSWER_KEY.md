## Key Frameworks Quick Reference

### Core Four
- Context, Model, Prompt, Tools

### PITER Framework
- Prompt Input, Trigger, Environment, Review

### R&D Framework
- Reduce, Delegate

### Three Constraints
- Context window, Codebase complexity, Our abilities

### SDLC Questions
- Plan: What are we building?
- Build: Did we make it real?
- Test: Does it work?
- Review: Is it what we planned?
- Document: How does it work?

### 7 Prompt Levels
1. High Level Prompt
2. Workflow Prompt
3. Control Flow
4. Delegation Prompt
5. Higher Order Prompts
6. Template Meta Prompt
7. Self-Improving Prompt

### Agent Evolution
Base → Better → More → Custom → Orchestrated

### ZTE Levels
In-Loop → Out-Loop → Zero-Touch Engineering

# TAC Course Excalidraw Diagrams

This directory contains presentation-ready Excalidraw diagrams for the Tactical Agentic Coding (TAC) course core concepts.

## Diagrams Created

### 1. **core-four.excalidraw**
The Core Four - In-Agent Leverage Points
- Shows the four fundamental in-agent leverage points
- Context (blue)
- Model (green)
- Prompt (orange)
- Tools (red)
- Connected with arrows showing relationships
- Frame: "The Core Four - In-Agent Leverage Points"

### 2. **12-leverage-points.excalidraw**
The Complete 12 Leverage Points
- **In-Agent Section** (Core Four): Context, Model, Prompt, Tools
- **Through-Agent Section**: Tests, Planning, ADWs, Documentation, Types, Architecture, CI/CD, Code Quality, Patterns
- Two color-coded sections showing the distinction
- Frame: "The 12 Leverage Points"

### 3. **piter-framework.excalidraw**
PITER Framework for AFK Agents
- **P**: Prompt Input (GitHub Issues) - orange
- **I**: Implied in flow
- **T**: Trigger (Webhooks) - green
- **E**: Environment (Dedicated) - red
- **R**: Review (Pull Requests) - purple
- Central "AFK Agent" hub with circular workflow
- Frame: "PITER Framework - AFK Agents"

### 4. **zte-workflow.excalidraw**
Zero-Touch Engineering Evolution
- **In-Loop** (orange): Plan → Build → Test
- **Out-Loop** (green): Review → Generate
- **ZTE** (red): Ship
- Shows progression with arrows
- Bottom note: "Increasing Automation & Decreasing Human Involvement"
- Frame: "Zero-Touch Engineering Workflow"

### 5. **7-prompt-levels.excalidraw**
The 7 Levels of Agentic Prompts
- Pyramid structure showing escalating sophistication
- **Level 1** (base - purple): High Level Prompt
- **Level 2** (purple): Workflow Prompt
- **Level 3** (blue): Control Flow
- **Level 4** (green): Delegation Prompt
- **Level 5** (yellow): Higher Order Prompts
- **Level 6** (orange): Template Meta Prompt
- **Level 7** (top - red): Self-Improving Prompt
- Frame: "The 7 Levels of Agentic Prompts"

### 6. **agent-evolution.excalidraw**
Agent Evolution Path
- Five stages showing progression:
  1. **Base Agents** (blue): Claude, Cursor, v0
  2. **Better Agents** (green): Context, Prompts, Tools
  3. **More Agents** (orange): Planning, Builder, Tester
  4. **Custom Agents** (purple): Domain, Specific, Workflows
  5. **Orchestrated Agents** (red): Multi-Agent, Coordination, ZTE
- Arrows showing progression
- Bottom note: "Increasing Capability & Autonomy"
- Frame: "Agent Evolution Path"

### 7. **agentic-layer.excalidraw**
The Agentic Layer Concept
- **Application Layer** (center - blue box):
  - DevOps
  - Infrastructure
  - Database
  - Application
- **Agentic Layer** (surrounding orange ring):
  - Tests, Documentation (left)
  - Planning, Architecture (right)
  - Context, Prompts (bottom)
- Shows 50%+ time allocation to building the agentic layer
- Bottom note: "Building the system that builds the system"
- Frame: "The Agentic Layer"

## Color Scheme

The diagrams use a consistent color palette:
- **Blue** (#1971c2): Primary concepts, foundational elements
- **Green** (#2f9e44): Growth, improvement, implementation
- **Orange** (#f08c00): Process, workflow, transformation
- **Red** (#e03131): Advanced, critical, final stages
- **Purple** (#5f3dc4): Specialized, meta-level concepts

## Usage

These diagrams are frame-ready for presentations and can be:
- Opened in Excalidraw (excalidraw.com)
- Edited and customized as needed
- Exported to PNG/SVG for presentations
- Used in course materials and documentation

## Frame Feature

All diagrams use Excalidraw's frame feature, making them:
- Easy to present in slide decks
- Clearly titled and organized
- Professional and polished
- Ready for export with proper boundaries

To use in Excalidraw:
1. Go to https://excalidraw.com
2. File → Open → Select the .excalidraw file
3. The diagram will load with the frame visible
4. Export via File → Export image (select frame if desired)

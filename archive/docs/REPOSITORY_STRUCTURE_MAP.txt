ARCHITECTURAL PATTERNS:

1. Three-System Integration:
   - Knowledge Management (Obsidian + Neo4j/Graphiti)
   - Observability (Langfuse + OpenTelemetry)
   - Automation (Skills + Hooks)

2. Event-Driven Automation:
   Session Events → Hooks (capture) → Python Scripts (process) → Storage (Neo4j, Langfuse, Obsidian) → Dashboards

3. Agent-Centric Task Management:
   - Archon (single source of truth)
   - Specialized agents for domains
   - Commands as operations
   - Skills as capability bundles

4. Reference Implementation Pattern:
   Each repo in claude-repos/ contains: ado/, agents/, commands/, skills/, templates/, settings.local.json

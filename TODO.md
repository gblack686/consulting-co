Getting into the AWS partner ecosystem for co-sell inbound deals + recurring revenue on customer cloud spend.

### Step 1 — Recertify AWS Cloud Practitioner
- [ ] Schedule exam at [aws.amazon.com/certification](https://aws.amazon.com/certification/certified-cloud-practitioner/)
- [ ] Cost: $50 (50% off for prior cert holders, cert lapsed >5 years ago)
- [ ] Prep: ~1–2 weeks review via AWS Skill Builder (free)
- [ ] **Solo founder note**: cert is needed for APN Select Tier but NOT required for FTR or ISV Accelerate

### Step 2 — Join AWS Partner Network (Free)
- [ ] Create AWS Partner Central account at [aws.amazon.com/partners](https://aws.amazon.com/partners/)
- [ ] Enroll in **Software Path** (free) — required for FTR and ISV Accelerate
- [ ] Enroll in **Services Path** ($2,500/year → receive $3,500 in AWS credits back) — SKIP for now, only needed for Solution Provider Program

### Step 3 — Complete Foundational Technical Review (FTR)
- [ ] Review Well-Architected checklist (security, reliability, operational excellence)
- [ ] Share 10 sales opportunities in ACE Pipeline Manager
- [ ] Submit FTR via AWS Partner Central (free, ~30 min with AI-assisted review)
- [ ] Unlocks: ISV Accelerate, AWS Competency, Marketplace listing

### Step 4 — Apply to AWS ISV Accelerate
> Source: 2026 AWS ISV Accelerate First Call Deck (via Grant Vasig, vasigr@amazon.com)
> Deck saved: `.claude/context/aws-partner/ISV_Accelerate_First_Call_Deck.pptx`

**Actual entrance requirements (Slide 9):**
- [ ] Software product listed as GA on AWS Marketplace (SaaS, AMI, Container, etc.)
- [ ] ACE Program eligibility achieved
- [ ] Software Path status: Validated or Differentiated
- [ ] Payee Central account setup at payeecentral.amazon.com
- [ ] Minimum **5 launched opportunities** in ACE within past 12 months (Primary Partner Need = "Co-Sell with AWS")
- [ ] Minimum **15 qualified opportunities** in ACE within past 12 months
- [ ] At least 1 person completed the Co-Selling with AWS learning module (free, Skill Builder)
- [ ] >= **$2,000 in recognized AWS Account revenue** at time of enrollment

**Key resources (Slide 11):**
- Partner Central ISV Accelerate guide: https://partnercentral.awspartner.com/partnercentral2/s/article?category=AWS_ISV_Accelerate
- Co-Selling with AWS learning module: https://skillbuilder.aws/learn/R5ZV5XXW99/aws-partner-coselling-with-aws/JNWX9WJRBG

**Note:** This is a pipeline program — AWS expects you to already be selling before enrolling. Need to build ACE opportunities first.

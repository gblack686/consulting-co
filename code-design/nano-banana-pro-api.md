# Nano Banana Pro API

## Overview
The Nano Banana Pro API provides access to advanced machine learning engines for generating high-quality 2K/4K AI images with features such as:
- Intent-driven composition
- Improved text rendering
- Consistent character generation
- AI image enhancement
- Background removal
- AI video generation support

```http

```

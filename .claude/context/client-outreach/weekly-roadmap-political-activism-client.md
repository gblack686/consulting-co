# 4-Week Engagement Roadmap — Political Activism Podcast & Instagram Client

**Date drafted**: 2026-04-03
**Engagement type**: Pro-bono / Partnership
**Deliverables**: Cross-platform metrics dashboard, programming automation

---

## Week 1: Discovery & Audit (Hours: ~3)

**Goal**: Understand the full picture — platforms, tools, pain points, and what "winning" looks like.

### Tasks
- [ ] **Discovery call** (30 min) — Walk through current workflow, platforms, and goals
  - What platforms are you on? (Podcast host, Instagram, TikTok, YouTube, website, newsletter?)
  - Where do you currently check metrics? How often?
  - What tasks eat the most time each week?
  - What does your posting/publishing workflow look like?
- [ ] **Platform & tool audit** — Document every tool and account with API availability
  - Podcast host (Spotify for Podcasters, Buzzsprout, Anchor, etc.)
  - Instagram (Meta Business Suite API)
  - Website/blog (analytics platform)
  - Newsletter (Mailchimp, Substack, etc.)
  - Any other social channels
- [ ] **Metrics inventory** — Identify which KPIs matter most
  - Podcast: downloads, listener retention, episode performance, subscriber growth
  - Instagram: follower growth, engagement rate, reach, saves, shares, story views
  - Website: traffic, referral sources, time on page
  - Cross-platform: audience overlap, content performance by format
- [ ] **Deliverable**: Platform audit document + prioritized automation list

---

## Week 2: Dashboard Build (Hours: ~5)

**Goal**: Stand up a working metrics dashboard that pulls real data from all platforms.

### Tasks
- [ ] **Connect API integrations** — Set up authenticated connections to each platform
  - Instagram Graph API (via Meta Business Suite)
  - Podcast analytics API (platform-dependent)
  - Google Analytics / website analytics
  - Newsletter platform API
- [ ] **Build aggregated dashboard** — Single-view metrics display
  - Daily/weekly/monthly views
  - Key metrics per platform with trend indicators
  - Automated data refresh (daily pull)
  - Exportable format (Google Sheet, Notion, or web dashboard)
- [ ] **Configure automated reporting** — Weekly summary delivered to inbox or Telegram
  - Top-performing content of the week
  - Follower/subscriber growth across platforms
  - Engagement trends (up/down/flat)
  - Suggested action items based on data
- [ ] **Deliverable**: Working dashboard + first automated weekly report

---

## Week 3: Content & Posting Automation (Hours: ~5)

**Goal**: Automate the repetitive parts of content publishing and cross-posting.

### Tasks
- [ ] **Content calendar automation** — Centralized scheduling system
  - Single place to plan podcast episodes + Instagram posts
  - Auto-reminders for recording, editing, publishing deadlines
  - Template-based posting (recurring series, quote cards, episode promos)
- [ ] **Cross-platform repurposing pipeline**
  - Podcast episode → audiogram clips for Instagram Reels
  - Podcast episode → pull quotes for Instagram carousel posts
  - Episode show notes → blog post draft or newsletter content
  - Instagram engagement highlights → podcast talking points
- [ ] **Engagement automation** — Smart notifications without spam
  - Alert when a post exceeds average engagement (capitalize on momentum)
  - Hashtag research and rotation automation
  - Comment/DM triage (flag important messages, auto-archive noise)
- [ ] **Deliverable**: Working content pipeline + repurposing templates

---

## Week 4: Optimization & Handoff (Hours: ~3)

**Goal**: Polish everything, document it, and make sure you can run it independently.

### Tasks
- [ ] **Dashboard tuning** — Adjust based on 2 weeks of real data
  - Remove metrics that don't matter, add ones you keep checking manually
  - Refine weekly report format based on feedback
  - Add comparison benchmarks (week-over-week, month-over-month)
- [ ] **Automation stress test** — Verify everything runs without intervention
  - Confirm all API connections are stable
  - Test failure handling (what happens when an API is down?)
  - Verify data accuracy against manual spot-checks
- [ ] **Documentation & training**
  - How-to guide for the dashboard (where to look, what the numbers mean)
  - Runbook for each automation (how to pause, modify, or restart)
  - List of "next phase" automation candidates for future work
- [ ] **Retrospective call** (30 min) — Review what we built, what's working, what's next
- [ ] **Deliverable**: Complete documentation package + trained client

# Complete Trace Metadata Schema (Phases 1-4)

## Overview

This document provides the complete metadata schema for traces generated by the Langfuse upgrade implementation (Phases 1-4). Each field is annotated with which phase introduced it.

---

## Trace-Level Metadata

```json
{
  "// Core Identification": {},
  "organization": "consulting-co",          // Project org (Phase 1)
  "project": "consulting-co",                // Project name (Phase 1)
  "project_id": "cmi19k90n000atd0713m9maij", // Project UUID (Phase 1)
  "timestamp": "2025-11-16T10:00:05Z",      // Trace creation time (Phase 1)

  "// Conversation Metrics": {},
  "user_message_length": 45,                 // Characters in user input (Phase 1)
  "assistant_message_length": 120,           // Characters in assistant output (Phase 1)
  "tool_count": 2,                           // Number of tools called (Phase 1)

  "// Phase 1: Event Tracking": {},
  "total_events_buffered": 7,                // Total hook events captured (Phase 1)
  "event_types_captured": {                  // Breakdown of event types (Phase 1)
    "SessionStart": 1,
    "UserPromptSubmit": 1,
    "PreToolUse": 2,
    "PostToolUse": 2,
    "Stop": 1
  },

  "// Phase 1: Tool Performance": {},
  "total_tool_latency_ms": 567,              // Time spent in tool calls (Phase 1)
  "conversation_latency_ms": 1234,           // Total time from user input to response (Phase 1)
  "llm_time_ms": 667,                        // Time spent in LLM (Phase 1)

  "// Phase 1: Tool Breakdown": {},
  "tool_timings": {                          // Per-tool timing breakdown (Phase 1)
    "Bash": 234,
    "Read": 333
  },

  "// Phase 3: Subagent Hierarchy": {},
  "is_subagent": false,                      // True if this is a subagent session (Phase 3)
  "parent_session_id": null,                 // Parent trace ID if subagent (Phase 3)
  "hierarchy_depth": 0,                      // Nesting level (0=root, 1+=subagent) (Phase 3)
  "subagent_count": 1,                       // Number of subagents spawned (Phase 3)

  "// Phase 4: Agent Metadata": {},
  "agent_id": "claude-code:session_abc",     // Display-friendly agent ID (Phase 4)
  "source_app": "claude-code",               // Source application name (Phase 4)
  "has_errors": false                        // Error flag for this trace (Phase 4)
}
```

## Tool Observation Metadata

```json
{
  "type": "SPAN",
  "name": "tool-Bash-1",
  "input": "{\"command\": \"ls -la\"}",
  "output": "file1.py\\nfile2.py\\n...",

  "metadata": {
    "// Phase 2: Tool Context": {},
    "event_type": "ToolInvocation",          // Constant (Phase 2)
    "tool_name": "Bash",                     // Name of the tool (Phase 2)
    "sequence_number": 1,                    // Sequential position (Phase 2)
    "latency_ms": 234,                       // Execution time in ms (Phase 2)
    "status": "success",                     // success/error (Phase 2)
    "error_message": null,                   // Error details if status=error (Phase 2)
    "start_timestamp": "2025-11-16T10:00:05Z", // When tool was called (Phase 2)
    "end_timestamp": "2025-11-16T10:00:05.234Z", // When tool completed (Phase 2)

    "// Phase 4: Agent Context": {},
    "agent_id": "claude-code:session_abc",   // Agent executing this tool (Phase 4)
    "source_app": "claude-code"              // Source application (Phase 4)
  }
}
```

## Subagent Observation Metadata

```json
{
  "type": "SPAN",
  "name": "subagent-session_def456",

  "metadata": {
    "// Phase 2: Basic Subagent Info": {},
    "event_type": "SubagentExecution",       // Constant (Phase 2)

    "// Phase 3: Hierarchy Tracking": {},
    "subagent_session_id": "session_def456", // Child session ID (Phase 3)
    "parent_session_id": "session_abc123",   // Parent session ID (Phase 3)
    "child_trace_id": "session_def456",      // Link to child trace in Langfuse (Phase 3)
    "hierarchy_depth": 1,                    // Nesting level (Phase 3)

    "// Subagent Details": {},
    "purpose": "Search codebase for patterns", // Why subagent was spawned (Phase 2)
    "outcome": "Found 3 files with matching patterns", // Result (Phase 2)
    "status": "completed",                   // completed/error/blocked (Phase 2)
    "timestamp": "2025-11-16T10:00:15Z",    // When subagent completed (Phase 2)

    "// Phase 4: Agent Context": {},
    "agent_id": "claude-code:session_abc",   // Parent agent ID (Phase 4)
    "source_app": "claude-code"              // Parent source app (Phase 4)
  }
}
```

## Usage Examples

### Query All Tools for an Agent

```python
traces = langfuse.get_traces(
    filter=[
        {"key": "metadata.agent_id", "value": "claude-code:session_a"}
    ]
)

for trace in traces:
    for obs in trace.observations:
        if obs.metadata.get("event_type") == "ToolInvocation":
            print(f"Tool: {obs.metadata['tool_name']}")
            print(f"Latency: {obs.metadata['latency_ms']}ms")
            print(f"Status: {obs.metadata['status']}")
```

### Find All Failed Tool Calls

```python
traces = langfuse.get_traces(
    filter=[
        {"key": "metadata.has_errors", "value": True}
    ]
)

for trace in traces:
    for obs in trace.observations:
        if obs.metadata.get("status") == "error":
            print(f"Failed: {obs.metadata['tool_name']}")
            print(f"Error: {obs.metadata['error_message']}")
```

### Analyze Subagent Performance

```python
parent_trace = langfuse.get_trace("session_abc123")

for obs in parent_trace.observations:
    if obs.metadata.get("event_type") == "SubagentExecution":
        subagent_id = obs.metadata["subagent_session_id"]
        child_trace = langfuse.get_trace(subagent_id)

        print(f"Subagent: {subagent_id}")
        print(f"Depth: {obs.metadata['hierarchy_depth']}")
        print(f"Tool calls: {len([o for o in child_trace.observations if o.metadata.get('event_type') == 'ToolInvocation'])}")
```

### Calculate Costs by Agent

```python
traces = langfuse.get_traces()
agent_costs = {}

for trace in traces:
    agent_id = trace.metadata.get("agent_id")
    tokens = sum(o.usage.total for o in trace.observations)
    cost = tokens * COST_PER_TOKEN

    if agent_id not in agent_costs:
        agent_costs[agent_id] = 0
    agent_costs[agent_id] += cost

for agent_id, cost in sorted(agent_costs.items(), key=lambda x: x[1], reverse=True):
    print(f"{agent_id}: ${cost:.4f}")
```

## Backward Compatibility

If ENABLE_ENHANCED_TRACING=false:
- Phase 2 metadata is NOT generated
- Phase 3 metadata is NOT generated
- Phase 4 metadata is NOT generated
- Only Phase 1 event tracking remains (optional)
- Trace structure reverts to simple GENERATION observation

To maintain backward compatibility while adding new features, Phase-level metadata is optional and can be safely ignored.

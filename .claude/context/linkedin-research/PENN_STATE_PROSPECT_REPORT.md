## Search Refinement Recommendations

### What Worked
- Google x-ray search (`site:linkedin.com/in`) was effective for extracting public LinkedIn profile data without requiring login
- Combining "Penn State University" with role keywords (CEO, CTO, VP, Founder) produced relevant results
- Adding industry qualifiers (technology, software, consulting, startup) in the third search significantly improved private-sector targeting

### Recommended Improvements for Next Run

1. **Log into LinkedIn in the MCP browser**: Store LinkedIn credentials in AWS Secrets Manager (`gbautomation/linkedin`) so the MCP browser can log in directly. This unlocks:
   - Connection degree visibility (1st, 2nd, 3rd)
   - Mutual connections data
   - More complete profile information
   - LinkedIn's native search filters (industry, company size, geography)

2. **Refine by geography**: Add geographic targeting for your local market or target regions:
   ```
   site:linkedin.com/in "Penn State" (CEO OR CTO OR Founder) ("New York" OR "Philadelphia" OR "Washington" OR "Boston")
   ```

3. **Refine by industry vertical**: Target specific industries where AI automation sells well:
   ```
   site:linkedin.com/in "Penn State" (CTO OR "VP Engineering" OR "VP Technology") (fintech OR healthtech OR SaaS OR "professional services")
   ```

4. **Exclude Penn State employees**: Many results are Penn State University staff rather than alumni working elsewhere. The `-university -academic` filter helped but could be stronger:
   ```
   -"Penn State University" +site:linkedin.com/in "Penn State" (CEO OR CTO)
   ```
   (This searches for profiles mentioning Penn State in education, not current employer)

5. **Use LinkedIn Sales Navigator**: If available, Sales Navigator provides far more granular filtering (school attended, current company, company headcount, etc.) and would be the ideal tool for this search.

6. **Follow-up enrichment**: For the top 10 prospects, visit each LinkedIn profile individually to gather:
   - Full work history
   - Recent posts/activity (for warm engagement topics)
   - Shared groups
   - Content they've published

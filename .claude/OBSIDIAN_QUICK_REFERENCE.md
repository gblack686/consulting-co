# 🚀 Obsidian Commands - Quick Reference

## Daily Commands

| Command | What It Does |
|---------|-------------|
| `/obsidian-daily` | Generate today's summary |
| `/obsidian-view` | View today's summary |
| `/obsidian-view 2025-11-13` | View specific date |

## Weekly Commands

| Command | What It Does |
|---------|-------------|
| `/obsidian-weekly` | Generate 7-day summary |
| `/obsidian-stats` | Show all-time statistics |

## Search & Explore

| Command | What It Does |
|---------|-------------|
| `/obsidian-search [term]` | Find entities & episodes |
| `/obsidian-graph [concept]` | Visualize connections |
| `/obsidian-episodes` | List recent conversations |

## Utilities

| Command | What It Does |
|---------|-------------|
| `/obsidian-schema` | Show database schema |
| `/obsidian-export` | Export to Obsidian files |
| `/obsidian-summary 2025-11-13` | Generate for specific date |

---

## 🎯 Quick Workflows

### Morning Review
```
/obsidian-view
```

### End of Day
```
/obsidian-daily
```

### Research Mode
```
/obsidian-search [topic]
/obsidian-graph [topic]
```

### Weekly Review (Friday/Sunday)
```
/obsidian-weekly
/obsidian-stats
```

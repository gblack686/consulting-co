# RevStar QuickStart Workflow Skill

## Installation

Copy this directory to your Claude Code skills folder:

```bash
cp -r revstar-quickstart-workflow C:\Users\gblac\.claude\skills\
```

Or extract the zip file:
```bash
unzip revstar-quickstart-workflow.zip -d C:\Users\gblac\.claude\skills\
```

## Usage

Claude will automatically use this skill when you mention:
- "Plan a QuickStart project"
- "Design a workflow"
- "Which agents do I need?"

## Structure

- `SKILL.md` - Main workflow guidance (6-step process)
- `references/` - Detailed documentation (stages, agents, conventions)
- `assets/` - YAML templates (data models, AWS services, UI specs, success criteria)

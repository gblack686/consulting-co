# Outreach Questions

## Discovery Questions (for DM conversations)

### Opening Questions
1. "What's the biggest time sink in your week right now?"
2. "If you could automate one thing tomorrow, what would it be?"
3. "What's stopping you from scaling faster?"

### Pain Point Questions
4. "How many hours/week do you spend on repetitive admin tasks?"
5. "What happens when you're out sick - does everything stop?"
6. "Have you tried automating anything before? What worked/didn't?"

### Budget & Timeline Questions
7. "If we could save you 10 hours/week, what would that be worth?"
8. "When do you need this solved by?"
9. "Is this a priority this quarter or more of a nice-to-have?"

## Qualifying Questions

### Decision Process
10. "Are you the one who'd make this decision, or is there a team?"
11. "What would make this a no-brainer for you?"
12. "What's your typical process for evaluating new tools/services?"

### Technical Fit
13. "What tools are you currently using for X?"
14. "Do you have any existing automations or workflows?"
15. "How technical is your team - do you have developers?"

### Red Flag Detection
16. "What's your timeline for making a change?"
17. "Is there budget allocated for this already?"
18. "What would prevent you from moving forward?"

## Objection Handling Questions

### Price Objections
- "Help me understand - is it the total cost or the monthly commitment?"
- "What would you expect to pay for a solution that saves you 15 hours/week?"
- "If we could show 10x ROI in month one, would the price still be a concern?"

### Timing Objections
- "What would need to change for the timing to be right?"
- "If we started today, when would you want to see results?"
- "Is there a specific event or deadline driving this?"

### Trust Objections
- "What would you need to see to feel confident moving forward?"
- "Would a pilot project help you evaluate us?"
- "Who else have you talked to about this?"

## Rapport-Building Questions

### Professional
- "How did you end up in {industry}?"
- "What's the most interesting project you're working on?"
- "Where do you see {company} in a year?"

### Connection
- "I saw you posted about {topic} - what got you interested in that?"
- "We have {mutual_connection} in common - how do you know them?"
- "Your background in {skill} is interesting - how does that help with {current_role}?"

## Conversation Flow Map

```
Opening Question
    │
    ├─> Pain expressed → Dig deeper with pain point questions
    │       │
    │       └─> Significant pain → Qualifying questions
    │               │
    │               └─> Qualified → Offer call
    │
    ├─> No pain → Rapport-building, try different angle
    │
    └─> Not a fit → Polite exit, ask for referral
```

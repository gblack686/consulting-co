# Outreach Domain Expert

## Overview

The Outreach Expert handles all prospecting, connection building, and initial conversation activities for GB Automation. Primary focus is LinkedIn outreach to generate qualified leads for AI consulting services.

| Area | Included |

| Connection requests | Yes |

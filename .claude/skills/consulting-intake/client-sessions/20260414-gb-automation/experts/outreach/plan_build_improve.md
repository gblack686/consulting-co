# Outreach: Plan-Build-Improve Protocol

## The Cycle

```
PLAN → BUILD → IMPROVE → VALIDATE → (repeat)
```

Every outreach campaign follows this cycle. Every message template. Every sequence.

## PLAN Phase

### Input
- Target segment definition
- Available messaging angles
- Current performance baselines
- Capacity constraints (daily limits)

### Activities
1. Define campaign objective (calls booked, responses, etc.)
2. Identify target accounts and contacts
3. Research prospects for personalization hooks
4. Draft message sequence
5. Set success metrics and thresholds

### Output
- Campaign brief with objectives and targets
- Prospect list with personalization notes
- Message templates ready for review
- Metric targets documented

## BUILD Phase

### Input
- Approved campaign plan
- Prospect list
- Message templates

### Activities
1. Personalize each message with prospect-specific details
2. Queue messages in sending tool
3. Set up tracking for responses
4. Configure alerts for hot leads
5. Prepare response templates

### Output
- Personalized message queue
- Tracking system configured
- Response playbook ready

## IMPROVE Phase

### Input
- Campaign performance data
- Response samples (positive and negative)
- Competitor messaging observations

### Activities
1. Analyze acceptance and response rates
2. Identify winning message patterns
3. Diagnose low-performing variants
4. Generate hypotheses for improvement
5. Update templates based on learnings

### Output
- Updated message templates
- Documented learnings
- Next iteration hypothesis

## VALIDATE Phase

### Input
- Improved templates
- Performance targets

### Activities
1. A/B test new templates against baseline
2. Measure statistically significant differences
3. Document what worked and why
4. Promote winners to new baseline
5. Archive losers with learnings

### Output
- Validated new templates
- Updated baseline metrics
- Learning log entry

## Iteration Frequency

| Component | Review Cycle |
|-----------|--------------|
| Individual messages | After 50 sends |
| Sequences | Weekly |
| Target segments | Bi-weekly |
| Overall strategy | Monthly |

## Improvement Triggers

Run an improvement cycle when:
- Response rate drops below 10%
- Acceptance rate drops below 25%
- Same template used for 2+ weeks without improvement
- New competitor messaging observed
- Market conditions change

## Learning Documentation

Every improvement cycle must document:
```markdown
## Improvement Log Entry

**Date**: {date}
**Component**: {message/sequence/segment}
**Baseline**: {metric before}
**Hypothesis**: {what we thought would work}
**Test**: {what we changed}
**Result**: {metric after}
**Learning**: {what we learned}
**Action**: {what changes permanently}
```

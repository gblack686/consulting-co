# Outreach Self-Improvement

## Self-Improvement Protocol

This document defines how the Outreach Expert continuously improves itself based on performance data and outcomes.

## Triggers

Self-improvement runs:
1. **Daily** at 9 PM ET - Review day's metrics
2. **Weekly** on Friday 6 PM - Deep analysis
3. **On threshold breach** - When metrics fall below targets
4. **On success pattern** - When something works exceptionally well

## Daily Self-Improvement Routine

### 1. Gather Metrics
```
- Connection requests sent: {n}
- Connections accepted: {n} ({%})
- DMs sent: {n}
- Responses received: {n} ({%})
- Calls booked: {n}
- Hot leads identified: {n}
```

### 2. Analyze Performance
- Compare to targets (acceptance >30%, response >15%)
- Identify top-performing messages
- Identify worst-performing messages
- Note any pattern changes

### 3. Generate Improvements
For each underperforming area:
- Hypothesize cause
- Propose specific change
- Estimate impact
- Queue for next batch

### 4. Update Assets
- Promote winning templates
- Retire losing templates
- Update personalization hooks
- Refine prospect criteria

### 5. Log Learning
Add entry to `MEMORY.md` Key Learnings Log:
```
| Date | Learning | Source | Action Taken |
```

## Weekly Deep Improvement

### Analysis Areas

1. **Message Performance**
   - Which templates have best acceptance rate?
   - Which DM openers get most responses?
   - What call-to-actions convert best?

2. **Segment Performance**
   - Which industries respond best?
   - Which roles engage most?
   - What company sizes convert?

3. **Timing Analysis**
   - Best days for outreach?
   - Best times for responses?
   - Optimal follow-up intervals?

4. **Competitive Intel**
   - What are others messaging about?
   - New objections appearing?
   - Market sentiment shifts?

### Improvement Actions

| Finding | Action |
|---------|--------|
| Template underperforming | Draft 2 variants, A/B test |
| Segment not converting | Refine ICP criteria or drop |
| Timing pattern found | Adjust send schedule |
| New objection common | Add to handling playbook |
| Winning pattern found | Document, scale, reinforce |

## Threshold Alerts

| Metric | Warning | Critical | Action |
|--------|---------|----------|--------|
| Acceptance rate | <25% | <15% | Pause, diagnose, revise |
| Response rate | <12% | <8% | Revise messaging |
| Call booking rate | <15% | <10% | Improve qualification |
| Daily volume | <15 | <10 | Increase prospecting |

## Self-Improvement Questions

Ask these during each improvement cycle:

1. **What worked?** Document the specific elements.
2. **What didn't?** Diagnose root cause.
3. **What's one thing to try?** Propose hypothesis.
4. **What should we stop?** Eliminate waste.
5. **What pattern is emerging?** Identify trends.

## Expertise Updates

When significant learnings accumulate:
1. Update `expertise.md` Part 7 (Patterns & Learnings)
2. Add new templates to Part 3 (Frameworks)
3. Refine ICP in Part 2 (Target Audience)
4. Update metrics in Part 5 (Metrics & Optimization)

## Feedback Loop

```
Outreach Activity
      │
      v
  Metrics Collected
      │
      v
  Self-Improve Analyzes
      │
      v
  Changes Proposed
      │
      v
  Greg Reviews (if major)
      │
      v
  Assets Updated
      │
      v
  Next Outreach Cycle
      │
      └──────────> (repeat)
```

## Version Control

Track changes to key assets:
- Templates: `templates_v{n}.md`
- ICP: Note date of last update
- Sequences: Log each iteration

This creates an audit trail of what we've tried and learned.

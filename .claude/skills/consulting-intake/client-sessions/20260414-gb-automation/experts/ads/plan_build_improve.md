# Ads: Plan-Build-Improve Protocol

## The Cycle

```
PLAN → BUILD → IMPROVE → VALIDATE → (repeat)
```

Every campaign, creative, and targeting approach follows this cycle.

## PLAN Phase

### Input
- Business goals (leads, calls, revenue)
- Budget constraints
- Target audience definition
- Available offers/content

### Activities
1. Define campaign objectives
2. Build audience segments
3. Plan creative variations
4. Set budget allocation
5. Define success metrics

### Output
- Campaign briefs
- Audience definitions
- Creative requirements
- Budget plan
- KPI targets

## BUILD Phase

### Input
- Campaign plans
- Audience segments
- Creative briefs
- Landing pages

### Activities
1. Set up campaigns in platform
2. Create ad creatives
3. Configure targeting
4. Set up tracking
5. Launch campaigns

### Output
- Live campaigns
- Tracking configured
- Creatives running
- Initial data flowing

## IMPROVE Phase

### Input
- Campaign performance data
- Lead quality feedback
- Creative metrics
- Audience insights

### Activities
1. Analyze performance by segment
2. Identify winning elements
3. Diagnose underperformers
4. Generate new hypotheses
5. Plan optimizations

### Output
- Updated targeting
- New creatives
- Budget reallocation
- Documented learnings

## VALIDATE Phase

### Input
- Optimization hypotheses
- Test designs
- Baseline metrics

### Activities
1. Run structured tests
2. Measure results
3. Validate improvements
4. Document winners
5. Update playbook

### Output
- Validated optimizations
- New baselines
- Scaled winners
- Documented learnings

## Iteration Frequency

| Component | Review Cycle |
|-----------|--------------|
| Daily metrics | Daily |
| Creative performance | Every 3 days |
| Audience performance | Weekly |
| Campaign strategy | Bi-weekly |
| Platform strategy | Monthly |

## Improvement Triggers

Run improvement cycle when:
- CPL rises 20% above baseline
- CTR drops below 0.5%
- Zero leads for 3 days
- Creative fatigue (declining CTR)
- Lead quality drops

## A/B Testing Protocol

### What to Test
1. **Audiences** (biggest impact)
2. **Offers** (what we promote)
3. **Creative** (image/video)
4. **Copy** (headline, body)
5. **CTAs** (button text)

### Testing Rules
- One variable at a time
- Minimum 500 impressions per variant
- Run for at least 3-5 days
- Document everything
- Kill clear losers fast

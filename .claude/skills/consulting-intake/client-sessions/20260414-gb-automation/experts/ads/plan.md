# Ads Planning

## Campaign Launch Plan

### Week 1: Foundation
1. Set up tracking (LinkedIn Insight Tag, Meta Pixel)
2. Build core audiences
3. Create 3-5 ad creatives
4. Set up lead magnets/landing pages
5. Launch first campaign

### Week 2: Learn
1. Monitor daily metrics
2. Identify early winners/losers
3. Pause obvious underperformers
4. Start first optimizations
5. Add new creative variants

### Week 3: Optimize
1. Double down on winners
2. Test new audiences
3. Refresh underperforming creative
4. Analyze lead quality
5. Adjust targeting

### Week 4: Scale
1. Increase budget on performers
2. Cut non-performers
3. Launch new campaign types
4. Add retargeting
5. Document learnings

## Daily Ads Routine

### Morning (5-10 min)
1. Check overnight spend and results
2. Review any new leads
3. Verify campaigns are running
4. Note any anomalies

### Midday (5 min)
1. Quick performance check
2. Pause anything burning budget
3. Follow up on new leads

### Evening (10 min)
1. Review full day metrics
2. Document learnings
3. Plan tomorrow's actions
4. Update tracking sheet

## Weekly Ads Routine

| Day | Focus |
|-----|-------|

## Campaign Structure

### LinkedIn Campaign Setup
```yaml
campaign_1_lead_gen:
  name: "GBA - Lead Gen - Free Audit"
  objective: "Lead Generation"
  audience: "Founders - Small Agencies"
  daily_budget: "$30"
  creatives: 3-5 variants
  
campaign_2_content:
  name: "GBA - Content - Case Study"
  objective: "Website Visits"
  audience: "Ops Leaders - SMB"
  daily_budget: "$15"
  creatives: 2-3 variants
```

### Meta Campaign Setup
```yaml
campaign_retargeting:
  name: "GBA - Retargeting - Visitors"
  objective: "Conversions"
  audience: "Website Visitors 30 days"
  daily_budget: "$10"
  creatives: 2-3 variants
```

### Scaling Triggers
- Scale when CPL < $40 for 5+ days
- Cut when CPL > $75 for 3+ days
- Pause when zero leads for 3+ days

## Creative Planning

### Creative Rotation
- Launch with 3-5 variants
- Add 1-2 new per week
- Pause after 2 weeks or fatigue
- Test: hook, image, offer, CTA

### Creative Calendar
| Week | Action |
|------|--------|
| 1 | Launch initial 3-5 |
| 2 | Add 2 new variants |
| 3 | Refresh underperformers |
| 4 | Scale winners, new tests |

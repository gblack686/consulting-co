# Jobs: Plan-Build-Improve Protocol

## The Cycle

```
PLAN → BUILD → IMPROVE → VALIDATE → (repeat)
```

Every job search campaign, application approach, and response strategy follows this cycle.

## PLAN Phase

### Input
- Target opportunity criteria
- Available job boards
- Current pipeline status
- Weekly capacity

### Activities
1. Define target roles/companies
2. Set weekly application targets
3. Schedule monitoring times
4. Prepare application templates
5. Set response goals

### Output
- Target criteria defined
- Weekly schedule set
- Templates ready
- Goals documented

## BUILD Phase

### Input
- Found opportunities
- Research on companies
- Application templates

### Activities
1. Research target companies
2. Personalize applications
3. Send applications
4. Handle responses
5. Conduct interviews

### Output
- Applications sent
- Responses handled
- Interviews completed
- Pipeline updated

## IMPROVE Phase

### Input
- Application response data
- Interview outcomes
- Win/loss patterns

### Activities
1. Analyze response rates
2. Identify winning applications
3. Note interview patterns
4. Update templates
5. Refine targeting

### Output
- Updated templates
- Refined criteria
- Better interview prep
- Documented learnings

## VALIDATE Phase

### Input
- New approaches
- Baseline metrics

### Activities
1. Test improved templates
2. Measure response rates
3. Document what works
4. Update expertise
5. Implement winners

### Output
- Validated improvements
- Updated baselines
- Learning documentation

## Iteration Frequency

| Component | Review Cycle |
|-----------|--------------|
| Individual applications | After outcome |
| Templates | Weekly |
| Target criteria | Bi-weekly |
| Overall strategy | Monthly |

## Improvement Triggers

Run improvement cycle when:
- Response rate drops below 10%
- Zero responses in a week
- Lost 2+ opportunities at same stage
- New job board or source found
- Market conditions shift

# Jobs Self-Improvement

## Self-Improvement Protocol

This document defines how the Jobs Expert continuously improves based on application outcomes and response patterns.

## Triggers

Self-improvement runs:
1. **Daily** at 9 PM ET - Review day's activity
2. **Weekly** on Friday 6 PM - Full analysis
3. **On response** - Analyze what worked
4. **On rejection** - Analyze what didn't

## Daily Self-Improvement Routine

### 1. Gather Metrics
```
Today's activity:
- Opportunities found: {n}
- Applications sent: {n}
- Responses received: {n}
- Interviews scheduled: {n}
```

### 2. Analyze Activity
- Which applications were strongest?
- Any responses to analyze?
- Interview performance?
- Pipeline health?

### 3. Quick Improvements
- Note effective hooks
- Update templates if needed
- Refine search criteria
- Adjust tomorrow's plan

### 4. Log Learning
```
| Date | Activity | Outcome | Learning |
```

## Weekly Deep Improvement

### Analysis Areas

1. **Response Rate Analysis**
   - Which applications got responses?
   - What did they have in common?
   - Which got ignored?
   - Pattern emerging?

2. **Source Analysis**
   - Which boards yield best opportunities?
   - Which are wasting time?
   - Any new sources to try?

3. **Messaging Analysis**
   - Which hooks work?
   - What proof points resonate?
   - Optimal length?
   - Best CTAs?

4. **Criteria Analysis**
   - Are we targeting right roles?
   - Rate expectations accurate?
   - Company types responding?

### Improvement Actions

| Finding | Action |
|---------|--------|
| Low response rate | Revise templates |
| Wrong opportunities | Refine criteria |
| Board underperforming | Reduce time on it |
| Hook working | Use it more |
| Interview failing | Improve prep |

## Jobs Metrics Dashboard

| Metric | Target | Warning | Critical |
|--------|--------|---------|----------|
| Applications/week | 10 | <5 | <2 |
| Response rate | 15% | <10% | <5% |
| Interview rate | 25% | <15% | <10% |
| Contracts/month | 1 | 0 | Multiple months |

## Self-Improvement Questions

Weekly review:

1. **What got responses?** Document the winning elements.
2. **What got ignored?** Diagnose the issues.
3. **Am I targeting right?** Adjust criteria if needed.
4. **What's one test?** Try something new.
5. **Is this channel worth it?** Evaluate ROI.

## Expertise Updates

When significant learnings accumulate:
1. Update `expertise.md` Part 7 (Patterns & Learnings)
2. Add new hooks/templates to Part 3
3. Refine target criteria in Part 2
4. Update board recommendations in Part 6

## Feedback Loops

### From Responses
- What made them respond?
- What are they looking for?
- How can I replicate?

### From Interviews
- What impressed them?
- Where did I lose them?
- Rate expectations aligned?

### From Pipeline
- Enough opportunities?
- Right quality?
- Moving fast enough?

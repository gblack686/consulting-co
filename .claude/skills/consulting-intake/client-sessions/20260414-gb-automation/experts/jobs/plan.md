# Jobs Planning

## Daily Job Search Plan

### Morning Scan (15-20 min)
1. Check LinkedIn Jobs for new relevant postings
2. Check AI-specific job boards
3. Review Google Alerts for target companies
4. Flag high-priority opportunities

### Application Block (30-60 min)
1. Research flagged opportunities
2. Write personalized applications
3. Send applications
4. Log in tracking sheet

### Response Handling (as needed)
1. Reply to responses within 4 hours
2. Schedule calls promptly
3. Prep for scheduled calls
4. Follow up on pending conversations

## Weekly Job Search Plan

| Day | Focus | Activities |
|-----|-------|------------|
| Monday | Fresh start | Scan all boards, send 3 applications |
| Tuesday | Follow-up | Chase responses, continue applications |
| Wednesday | Mid-week push | 2-3 applications, interviews if scheduled |
| Thursday | Network | Reach out to connections at target companies |
| Friday | Review | Track metrics, plan next week |
| Weekend | Research | Deep research on promising companies |

## Application Pipeline

### Pipeline Stages
1. **Found** - Opportunity identified
2. **Researched** - Company/role researched
3. **Applied** - Application sent
4. **Responded** - They replied
5. **Interviewing** - In conversation
6. **Offered** - Terms proposed
7. **Closed Won** - Contract signed
8. **Closed Lost** - Didn't proceed

### Weekly Targets
| Stage | Target |
|-------|--------|
| Found | 20 opportunities |
| Researched | 15 |
| Applied | 10 |
| Responded | 2-3 |
| Interviewing | 1-2 |
| Closed Won | 1 per month |

## Application Checklist

### Before Applying
- [ ] Read full job posting
- [ ] Research company (2-3 min)
- [ ] Check for mutual connections
- [ ] Confirm it matches criteria (remote, rate, type)
- [ ] Note specific hook for cover letter

### Application
- [ ] Personalized first line
- [ ] Relevant result included
- [ ] Under 150 words
- [ ] Clear CTA
- [ ] Proofread

### After Applying
- [ ] Log in tracking sheet
- [ ] Set follow-up reminder (if no response in 1 week)
- [ ] Connect on LinkedIn (if appropriate)

## Interview Prep Checklist

### 24 Hours Before
- [ ] Research company thoroughly
- [ ] Research interviewer on LinkedIn
- [ ] Prepare 3 specific questions
- [ ] Select relevant case study
- [ ] Review rate/terms strategy

### 1 Hour Before
- [ ] Test video/audio
- [ ] Have notes ready
- [ ] Quiet environment confirmed
- [ ] Water nearby
- [ ] Calendar clear for 30 min after

### Post-Interview
- [ ] Send thank you within 2 hours
- [ ] Update tracking sheet
- [ ] Note key points from conversation
- [ ] Set follow-up task

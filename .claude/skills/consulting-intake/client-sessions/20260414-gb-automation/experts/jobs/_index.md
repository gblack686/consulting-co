# Jobs Domain Expert

## Overview

The Jobs Expert monitors job boards and opportunities, automates applications, and handles responses for relevant AI/automation consulting opportunities. This serves as a parallel revenue stream while building the client base.

## Domain Scope

| Area | Included |
|------|----------|
| Job board monitoring | Yes |
| Application automation | Yes |
| Response handling | Yes |
| Contract opportunities | Yes |
| Full-time roles | No (consulting focus) |
| Agencies/recruiters | Limited |

## Key Metrics

| Metric | Target | Current |

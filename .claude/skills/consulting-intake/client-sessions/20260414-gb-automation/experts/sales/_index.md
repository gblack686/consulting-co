# Sales Domain Expert

## Overview

The Sales Expert handles all activities from qualified lead to signed contract, including discovery calls, proposals, negotiations, and onboarding handoff.

## Domain Scope

| Area | Included |
|------|----------|
| Discovery calls | Yes |
| Proposal creation | Yes |
| Pricing strategy | Yes |
| Objection handling | Yes |
| Contract negotiation | Yes |
| Onboarding handoff | Yes |
| Post-sale support | No (future domain) |

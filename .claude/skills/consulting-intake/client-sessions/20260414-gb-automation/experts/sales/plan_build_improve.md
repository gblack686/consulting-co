# Sales: Plan-Build-Improve Protocol

## The Cycle

```
PLAN → BUILD → IMPROVE → VALIDATE → (repeat)
```

Every sales process, pitch, and proposal follows this cycle.

## PLAN Phase

### Input
- Lead source and context
- Discovery call notes
- Pipeline capacity
- Revenue targets

### Activities
1. Review incoming leads
2. Prioritize by fit and urgency
3. Prepare for discovery calls
4. Plan proposal approach
5. Set conversion targets

### Output
- Prioritized lead list
- Call preparation notes
- Proposal outlines
- Target metrics

## BUILD Phase

### Input
- Discovery insights
- Client pain points
- Pricing guidelines
- Case study library

### Activities
1. Conduct discovery calls
2. Draft tailored proposals
3. Create ROI calculations
4. Prepare objection responses
5. Send proposals

### Output
- Completed discovery notes
- Sent proposals
- Follow-up sequences
- Updated pipeline

## IMPROVE Phase

### Input
- Win/loss data
- Call recordings/notes
- Proposal feedback
- Competitor intel

### Activities
1. Analyze conversion rates
2. Review lost deal reasons
3. Identify winning patterns
4. Update talk tracks
5. Refine proposal templates

### Output
- Updated sales playbook
- Improved proposals
- New objection handlers
- Pattern documentation

## VALIDATE Phase

### Input
- New approaches
- Baseline metrics

### Activities
1. Test new approaches
2. Measure conversion impact
3. Document what works
4. Update expertise
5. Train on changes

### Output
- Validated improvements
- Updated baselines
- Team documentation

## Iteration Frequency

| Component | Review Cycle |
|-----------|--------------|
| Individual deals | After outcome |
| Talk tracks | Weekly |
| Proposal templates | Monthly |
| Pricing | Quarterly |

## Improvement Triggers

Run improvement cycle when:
- Close rate drops below 35%
- Same objection appears 3+ times
- Lost 2+ deals for same reason
- New competitor offering emerges
- Market conditions shift

## Win/Loss Analysis

After every deal:
1. What worked well?
2. What could have been better?
3. Was qualifying accurate?
4. Was pricing right?
5. What would we do differently?

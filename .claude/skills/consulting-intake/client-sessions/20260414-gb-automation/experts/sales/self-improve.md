# Sales Self-Improvement

## Self-Improvement Protocol

This document defines how the Sales Expert continuously improves based on deal outcomes and conversion data.

## Triggers

Self-improvement runs:
1. **Daily** at 9 PM ET - Review day's activity
2. **Weekly** on Friday 6 PM - Win/loss analysis
3. **After every closed deal** - Win or loss analysis
4. **On pattern detection** - Same objection 3+ times

## Daily Self-Improvement Routine

### 1. Gather Metrics
```
Today's activity:
- Discovery calls: {n}
- Proposals sent: {n}
- Follow-ups made: {n}
- Deals moved forward: {n}
- Deals closed: {n}
- Revenue closed: ${n}
```

### 2. Analyze Activity
- Were calls effective? (advancement rate)
- Was follow-up timely?
- Any new objections encountered?
- Pipeline movement?

### 3. Quick Improvements
- Note effective talk tracks
- Capture new objections
- Update follow-up approach
- Adjust tomorrow's priorities

### 4. Log Learning
```
| Date | Activity | Outcome | Learning |
```

## Weekly Deep Improvement

### Analysis Areas

1. **Conversion Analysis**
   - Lead to discovery rate
   - Discovery to proposal rate
   - Proposal to close rate
   - Overall win rate

2. **Loss Analysis**
   - Why did we lose?
   - At what stage?
   - Preventable or not?
   - Pattern emerging?

3. **Win Analysis**
   - Why did we win?
   - What worked well?
   - Replicable factors?
   - Reference potential?

4. **Pipeline Analysis**
   - Enough leads?
   - Deals stuck at any stage?
   - Velocity acceptable?
   - Forecast accuracy?

### Improvement Actions

| Finding | Action |
|---------|--------|
| Low discovery rate | Improve qualification |
| Low proposal rate | Improve discovery questions |
| Low close rate | Improve proposals/handling |
| Long cycle | Add urgency, improve follow-up |
| Lost to price | Better value articulation |

## Sales Metrics Dashboard

| Metric | Target | Warning | Critical | Action |
|--------|--------|---------|----------|--------|
| Discovery calls/week | 5 | <3 | <1 | More outreach |
| Discovery to proposal | 60% | <50% | <30% | Better discovery |
| Proposal to close | 40% | <30% | <20% | Better proposals |
| Avg deal size | $3,500 | <$3,000 | <$2,500 | Hold pricing |
| Cycle length | <14 days | >21 days | >30 days | Add urgency |

## Self-Improvement Questions

Ask during each cycle:

1. **What closed deals?** Document the winning pattern.
2. **What lost deals?** Diagnose the failure mode.
3. **What objections repeated?** Add to playbook.
4. **What's blocking pipeline?** Remove the bottleneck.
5. **What's one experiment?** Test something new.

## Expertise Updates

When significant learnings accumulate:
1. Update `expertise.md` Part 7 (Patterns & Learnings)
2. Add new objection handlers to Part 5
3. Refine discovery questions in Part 4
4. Update pricing if needed in Part 2

## Feedback Loops

### From Closed Won
- What worked? → Repeat it
- What did they value? → Emphasize it
- Would they refer? → Ask them

### From Closed Lost
- Why really? → Fix it
- Preventable? → Process change
- Competitive loss? → Intel gathering

### From Pipeline
- What's stuck? → Unstick it
- What's cold? → Warm or close
- What's hot? → Prioritize it

## Competitive Intelligence

Track:
- Who else they talked to
- What offerings they compared
- Why they chose/didn't choose us
- Pricing they mentioned

Use to:
- Refine positioning
- Adjust pricing if needed
- Improve discovery questions
- Update talk tracks

# Sales Planning

## Daily Sales Plan

### Morning Block (9-11 AM)
1. Review pipeline and prioritize (15 min)
2. Prepare for scheduled calls (30 min)
3. Conduct discovery calls (1+ hours)
4. Send proposals within 4 hours of call

### Afternoon Block (2-4 PM)
1. Follow up on pending proposals (30 min)
2. Handle objections and questions (30 min)
3. Update CRM with all activity (15 min)
4. Prep for tomorrow's calls (15 min)

## Weekly Sales Plan

| Day | Focus | Key Activities |
|-----|-------|----------------|
| Monday | Pipeline review | Prioritize, plan week, early calls |
| Tuesday | Discovery heavy | 2-3 discovery calls, proposals |
| Wednesday | Mid-week push | Follow-ups, new calls |
| Thursday | Close focus | Proposal follow-ups, negotiations |
| Friday | Admin + prep | Close deals, update CRM, plan next week |

## Pipeline Management

### Pipeline Stages
1. **Lead** - Qualified from outreach
2. **Discovery Scheduled** - Call booked
3. **Discovery Complete** - Needs assessment done
4. **Proposal Sent** - Waiting for response
5. **Negotiation** - Discussing terms
6. **Verbal Yes** - Awaiting contract
7. **Closed Won** - Signed and paid
8. **Closed Lost** - Did not proceed

### Stage Targets (for 3 contracts/month)
| Stage | Target Count | Conversion |
|-------|--------------|------------|
| Leads | 20 | 50% to Discovery |
| Discovery | 10 | 60% to Proposal |
| Proposal | 6 | 50% to Close |
| Won | 3 | - |

### Velocity Targets
| Metric | Target |
|--------|--------|
| Lead to Discovery | <3 days |
| Discovery to Proposal | <24 hours |
| Proposal to Decision | <7 days |
| Total Cycle | <14 days |

## Call Planning

### Pre-Call Checklist
- [ ] Research prospect on LinkedIn
- [ ] Review company website
- [ ] Note any content engagement
- [ ] Prepare 3 personalized questions
- [ ] Have case study ready to share
- [ ] Test call link/technology
- [ ] Block time for proposal after

### Discovery Call Structure
```
:00 - :02  Welcome & rapport
:02 - :05  Set agenda
:05 - :15  Situation questions
:15 - :25  Problem/pain questions
:25 - :30  Implications & urgency
:30 - :35  Qualification
:35 - :40  High-level solution fit
:40 - :45  Next steps & timeline
```

### Post-Call Checklist
- [ ] Send thank you email (within 1 hour)
- [ ] Update CRM with notes
- [ ] Draft proposal (within 4 hours)
- [ ] Schedule follow-up task
- [ ] Share insights with team

## Proposal Planning

### Proposal Timeline
- Hour 0-1: Draft based on call notes
- Hour 1-2: Add case study and ROI
- Hour 2-4: Review and send
- Day 2: Follow-up if no response
- Day 5: Second follow-up
- Day 7: Direct ask

### Proposal Checklist
- [ ] Reflects their specific pain points
- [ ] Includes relevant case study
- [ ] ROI calculation included
- [ ] Pricing is clear
- [ ] Next steps are obvious
- [ ] Urgency element included

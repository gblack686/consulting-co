# Content: Plan-Build-Improve Protocol

## The Cycle

```
PLAN → BUILD → IMPROVE → VALIDATE → (repeat)
```

Every content piece, campaign, and strategy follows this cycle.

## PLAN Phase

### Input
- Content goals (awareness, engagement, leads)
- Target audience insights
- Previous performance data
- Current content bank

### Activities
1. Define content objective for the period
2. Select topics from content bank
3. Choose formats based on performance data
4. Map CTAs to business goals
5. Set engagement targets

### Output
- Content calendar for the period
- Topic briefs with angles
- Format specifications
- Success metrics defined

## BUILD Phase

### Input
- Content calendar
- Topic briefs
- Brand voice guidelines

### Activities
1. Draft content using frameworks
2. Create supporting visuals
3. Write hooks and CTAs
4. Format for LinkedIn
5. Queue for scheduling

### Output
- Completed content pieces
- Scheduled posts
- Engagement plan ready

## IMPROVE Phase

### Input
- Published content performance
- Audience feedback (comments, DMs)
- Competitor content analysis

### Activities
1. Analyze engagement metrics
2. Identify what resonated (and why)
3. Note audience questions/objections
4. Compare to competitors
5. Update content frameworks

### Output
- Performance insights
- Updated frameworks
- New topic ideas
- Refined voice guidelines

## VALIDATE Phase

### Input
- Improved content approach
- Baseline metrics

### Activities
1. Test new approaches against baseline
2. Measure statistical significance
3. Document what worked
4. Update expertise knowledge
5. Retire underperforming approaches

### Output
- Validated improvements
- Updated baselines
- Learning documentation

## Iteration Frequency

| Component | Review Cycle |
|-----------|--------------|
| Individual posts | After 48 hours |
| Weekly themes | End of week |
| Content pillars | Monthly |
| Overall strategy | Quarterly |

## Improvement Triggers

Run improvement cycle when:
- Engagement drops below 3%
- Zero inbound DMs in a week
- New competitor content outperforms
- Audience feedback suggests gap
- Platform algorithm changes

## Content A/B Testing

### What to Test
- Hook styles (question vs statement vs statistic)
- Post length (short vs long)
- Format (text vs carousel vs image)
- CTA type (engage vs follow vs DM)
- Posting time (morning vs afternoon)

### Testing Protocol
1. Isolate ONE variable
2. Alternate over 10 posts
3. Measure engagement rate
4. Calculate statistical significance
5. Implement winner

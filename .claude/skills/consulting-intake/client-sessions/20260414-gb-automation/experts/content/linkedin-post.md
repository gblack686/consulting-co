# Command: LinkedIn Post

## Purpose
Create LinkedIn posts optimized for engagement and lead generation.

## Usage
```
/content linkedin-post {topic} [--format {text|carousel|image}] [--pillar {build|client|insight|personal}]
```

## Input
- Topic or angle
- Format preference (optional)
- Content pillar (optional)
- Specific details to include (optional)

## Process

### Step 1: Topic Research
If topic is vague:
1. Check content bank for related ideas
2. Search recent conversations for angles
3. Look at competitor content for gaps
4. Review audience questions

### Step 2: Select Framework

Based on topic type:

| Topic Type | Framework |
|------------|-----------|
| Story/experience | Hook-Story-CTA |
| Tactical/how-to | Listicle |
| Opinion/stance | Contrarian |
| Results/wins | Before/After |

### Step 3: Draft Content

**Structure**:
```
[LINE 1-2: HOOK - must stop the scroll]

[LINE 3-10: BODY - the main content]

[LINE 11-12: CTA - what reader should do]
```

**Hook Types**:
- **Question**: "What if I told you..."
- **Bold claim**: "I made $X in Y doing Z."
- **Statistic**: "93% of people don't know..."
- **Contrarian**: "Unpopular opinion: ..."
- **Story opener**: "Last week, a client told me..."

### Step 4: Optimize for LinkedIn

Checklist:
- [ ] Hook in first 2 lines (before "see more")
- [ ] Line breaks between paragraphs
- [ ] 150-300 words total
- [ ] One core idea
- [ ] Active voice
- [ ] Specific numbers/examples
- [ ] Clear CTA

### Step 5: Add Visual (if needed)

| Format | When to Use |
|--------|-------------|
| Text only | Stories, opinions, quick takes |
| Single image | Screenshots, quotes, data |
| Carousel | How-tos, lists, step-by-step |
| Video | Tutorials, testimonials (future) |

### Step 6: Schedule

Queue post for optimal time:
- Weekdays: 8-10 AM or 12-1 PM (audience timezone)
- Avoid: Weekends, Friday afternoons

## Output

```markdown
## LinkedIn Post Draft

**Topic**: {topic}
**Pillar**: {pillar}
**Framework**: {framework}
**Scheduled**: {datetime}

---

{full_post_text}

---

**Visual**: {none | attached | carousel X slides}
**CTA Type**: {engage | follow | DM | link}
**Target Engagement**: {based on topic/format}
```

## Post Templates

### Template: Behind the Build
```
Building in public:

{What you're working on}

{Why it matters}

{Specific detail/screenshot}

{What's next}

What would you want to see me tackle next?
```

### Template: Client Win
```
Client update:

{Client type} came to us with {problem}.

{Time period} later:
- {Result 1}
- {Result 2}
- {Result 3}

The key? {One insight}

{CTA}
```

### Template: Quick Tip
```
{Outcome} hack:

{The tip in one line}

Here's why it works:

{Explanation in 2-3 lines}

Try it and let me know how it goes.
```

## Quality Gate

Before publishing, verify:
- [ ] Would I stop scrolling for this hook?
- [ ] Is there ONE clear takeaway?
- [ ] Does this sound like a human, not a brand?
- [ ] Is the CTA clear and natural?
- [ ] Did I proofread for typos?

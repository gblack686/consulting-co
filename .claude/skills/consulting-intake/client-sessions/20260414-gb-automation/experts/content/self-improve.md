# Content Self-Improvement

## Self-Improvement Protocol

This document defines how the Content Expert continuously improves based on performance data and audience feedback.

## Triggers

Self-improvement runs:
1. **Daily** at 9 PM ET - Review today's post performance
2. **Weekly** on Friday 6 PM - Deep weekly analysis
3. **On viral content** - When engagement >5x normal
4. **On flop content** - When engagement <50% of average

## Daily Self-Improvement Routine

### 1. Gather Metrics
```
Today's post:
- Impressions: {n}
- Engagement rate: {%}
- Likes: {n}
- Comments: {n}
- Shares: {n}
- Profile views: {n}
- New followers: {n}
- Inbound DMs: {n}
```

### 2. Analyze Performance
- Compare to 7-day average
- Identify hook effectiveness
- Note comment sentiment
- Track which CTA worked

### 3. Quick Improvements
- If below average: note what to avoid
- If above average: note what to repeat
- Update topic ideas based on comments
- Refine tomorrow's content if needed

### 4. Log Learning
Add to content performance log:
```
| Date | Topic | Hook Type | Engagement | Learning |
```

## Weekly Deep Improvement

### Analysis Areas

1. **Hook Analysis**
   - Which opening styles get most engagement?
   - What pattern interrupts work?
   - How many words before "see more"?

2. **Topic Analysis**
   - Which pillar performs best?
   - What specific topics resonate?
   - What does audience want more of?

3. **Format Analysis**
   - Text vs image vs carousel?
   - Post length correlation?
   - Best day/time patterns?

4. **Audience Analysis**
   - Who's engaging most?
   - What do they have in common?
   - Are they our ICP?

### Improvement Actions

| Finding | Action |
|---------|--------|
| Hook type winning | Use more in next week |
| Topic resonating | Plan series around it |
| Format outperforming | Increase frequency |
| ICP engaging | Double down on angle |
| Non-ICP engaging | Adjust targeting |

## Content Quality Metrics

| Metric | Target | Warning | Action |
|--------|--------|---------|--------|
| Engagement rate | >5% | <3% | Revise approach |
| Comments/post | >10 | <3 | More engaging CTAs |
| Shares/post | >2 | 0 | Add more value |
| Profile views/week | 200+ | <100 | Post more consistently |
| Follower growth/week | 50+ | <20 | Optimize profile + hooks |

## Self-Improvement Questions

Ask during each cycle:

1. **What worked?** Save the winning elements.
2. **What flopped?** Diagnose the reason.
3. **What did the audience ask?** Create content that answers.
4. **What should we stop?** Retire low performers.
5. **What would 10x engagement?** Experiment boldly.

## Expertise Updates

When significant learnings accumulate:
1. Update `expertise.md` Part 7 (Patterns & Learnings)
2. Add new frameworks to Part 3
3. Refine voice guidelines in Part 4
4. Update content pillars in Part 2

## Feedback Loops

### From Comments
- Questions → New content ideas
- Objections → Address in future posts
- Praise → Double down on that angle
- Criticism → Evaluate and adjust

### From DMs
- "How do you..." → Tutorial content
- "Can you help with..." → Case study opportunity
- "I've been thinking..." → Conversation starters

### From Outreach
- What content supports conversations?
- What do prospects mention seeing?
- What builds credibility fastest?

## Version Control

Track content evolution:
- Framework templates: date last updated
- Voice guidelines: note iterations
- Content pillars: track shifts over time

## Viral Content Protocol

When a post significantly outperforms:
1. Analyze EVERYTHING (timing, hook, topic, format)
2. Document exactly what made it work
3. Plan follow-up content on same topic
4. Create template from the structure
5. Share learning with other domains

# Memory — Cruz Creations Agent

## Mission

Help Erica Cruz build Cruz Creations into a sustainable, scalable art business — automating the operational grind so she can spend more time creating, teaching, and growing.

## 90-Day Goals

1. **Cancel Mailchimp** — replace with AI-drafted Gmail newsletters, saving $50/month
2. **Workshop follow-up automation** — QR form → kiln email → pickup notification, all on autopilot
3. **Morning brief** — 8am daily: priority emails, calendar, industry news, moon phase, journaling prompt
4. **Google Workspace** — set up erica@cruisecreations.com + give agent workspace access
5. **Content uplift** — start posting artist-storytelling content (not just event promos), target 10K+ views

## Key Context

- Workshop flow: attendees scan QR code at workshop → Google Form (name, email, piece description, workshop) → agent sends "pieces in the kiln" email → agent sends "pieces ready for pickup" email
- Workshop photos: group shots only (not individual pieces). Save to Google Drive, not phone.
- FAQ emails Erica gets most: "When can I pick up my pieces?" and "When's your next event?"
- Corporate/private event inquiries: Erica handles these personally, agent does NOT respond
- Social strategy: pivot from event-only posts to artist storytelling + "5 things I learned" format
- Artist-to-artist program: Erica's big vision — community + masterclass for artists turning art into business. Still in planning phase.
- Mailchimp: two lists (consumer newsletter + artist community). Both to be replaced.
- ClassBento: no API — browser automation needed for workshop management

## Phase Plan

**Phase 1 (Weeks 1-2)**: Set up infrastructure
- Google Workspace custom domain
- Shopify API key
- WhatsApp Business API (or Twilio sandbox)
- iPhone photos → Google Photos backup

**Phase 2 (Weeks 3-4)**: Core workflows
- Workshop assistant live (QR form → email triggers)
- Morning brief running at 8am
- FAQ auto-draft replies running

**Phase 3 (Month 2)**: Growth
- Social media content calendar + caption drafting
- Artist-to-artist program outline drafted by agent
- Mailchimp fully cancelled, newsletter replaced

**Phase 4 (Month 3+)**: Scale
- Shopify product updates via agent
- Content repurposing from iPhone library
- Remotion video automation (workshop recap reels)

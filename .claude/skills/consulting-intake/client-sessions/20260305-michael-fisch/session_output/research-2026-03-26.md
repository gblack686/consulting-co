# Research Notes — Fisch Group Session 2026-03-26

## 1. Claude Co-Work vs Claude Code: Skills

Both use the same SKILL.md format — fully portable.

- **Code**: `.claude/skills/your-skill/SKILL.md` (project) or `~/.claude/skills/` (global)
- **Co-Work**: GUI Skills Directory, Customize > Skills
- Anthropic publishes a **skill-creator** skill (117k weekly installs)

**Transfer workflow:**
- Code → Co-Work: ZIP the folder, upload via Settings > Customize > Skills > "+" > Upload
- Co-Work → Code: Download the skill folder, place in `.claude/skills/`
- Best practice: commit to shared Git repo

## 2. Lovable.dev + Supabase

Lovable uses Supabase as backend. "Lovable Cloud" = a managed Supabase instance.

**Migration options:**
1. `supabase db pull` + `supabase db dump` → `supabase link` + `supabase db push`
2. SQL migration files in `supabase/migrations/`
3. Chrome extension: "Lovable Cloud to Supabase Migration Tool"
4. Dreamlit AI open-source exporter

**Bottom line:** They own their data. Can migrate to own Supabase anytime.

## 3. QuickBooks Multi-Company Access

Currently one QBO company (realmId) per MCP connection.

**Workarounds:**
1. Multiple MCP server instances (one per client company)
2. CData Connect AI (aggregates multiple QBO entities)
3. n8n/Zapier middleware
4. Intuit + Anthropic partnership (Feb 2026) — Spring 2026 rollout targets multi-entity businesses

## 4. Skill Sharing

# Consulting Pipeline Phases

Seven lifecycle phases for classifying skills. Each phase has keywords used for auto-classification.

| Phase | Description | Keywords |
|-------|-------------|----------|
| Prospect | Finding and qualifying leads | linkedin, prospect, recon, social, research, intel, outreach |
| Onboard | Welcome, setup, admin | onboard, welcome, admin, email, drive, folder, deck, setup, new-client |
| Discover | Understanding client needs | discover, question, intake, interview, workflow, ideator, transcript |
| Build | Creating deliverables | build, scaffold, agent, skill, code, repo, workspace, template, deploy |
| Deploy | Shipping to production | deploy, github-actions, ci, cd, lightsail, openclaw, production |
| Monitor | Ongoing observation | monitor, heartbeat, inbox, log, sync, graphify, daily, scan, watch |
| Grow | Expanding engagement | grow, proposal, upsell, expand, renew, report |

## Cross-Cutting

Skills that serve multiple phases or the system itself:

| Category | Keywords |
|----------|----------|
| Meta | meta, discovery, inventory, scan, index, archive, sync, knowledge |
| Operations | cost, budget, billing, infrastructure, secret, credential |
